# Nextellar Cookbook

Worked recipes showing how to combine Nextellar template hooks and helpers for common Stellar and Soroban workflows.

- [Deploying and Upgrading a Soroban Contract](contract-deploy-and-upgrade.md) — End-to-end `useContractDeploy` and `useContractUpgrade` flow.
- [Calling Soroban Contracts (`useSorobanContract`)](useSorobanContract.md) — Read/write invocations, simulation, and argument encoding.
- [Sending Stellar Payments (`useStellarPayment`)](useStellarPayment.md) — Native XLM and issued asset transfers.
- [DEX Swaps & Path Payments (`usePathPayment`)](usePathPayment.md) — Strict-send, strict-receive, slippage bounds, and error handling.
